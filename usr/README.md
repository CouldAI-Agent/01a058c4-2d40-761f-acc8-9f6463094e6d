# Offer Letter Generator

This is a Flutter application that allows users to view and generate an offer letter PDF based on user input.

## Features

- Fill out a form to generate a customized offer letter.
- Preview and print or share the generated PDF directly from the app.
- Built using Flutter with the `pdf` and `printing` packages.

## Getting Started

1. Ensure you have Flutter installed.
2. Run `flutter pub get` to fetch dependencies.
3. Run the app on your preferred platform using `flutter run`.

## Tech Stack

- Flutter
- `pdf` package for generating PDFs
- `printing` package for previewing and sharing PDFs
